1. 先搞懂：P 和 D 到底在干什么

把开车想象成你妈让你把车停进车位：

一句话你车上的体现
P（比例）现在偏了多少，就打多少角偏 20 个像素 × P=1.9 = 打 38 个单位的角度。P 是主力，没有它车不转弯
D（微分）偏离得越来越快，就提前多打一点看的是"这一帧比上一帧多偏了多少"。P 冲过头之前踩刹车
只有 P 的车：像喝多的人走路，永远在赛道左右两边来回撞（震荡）。
P + 合适 D：平稳收敛到中线。
D 太大：神经质，误差数字稍微一抖它就猛打舵（高频抖动）。

2. 现象 → 参数 对照表

调参 90% 的时间就是对着这张表查：

看到的现象诊断怎么动
直道画龙 车头左右摆，走 S 形P 太大（修过头），或 D 太小（收不住）先退 P，退到不画龙；还摆就加 D
弯道外冲 车往外飞、压边线出界P 太小（打角不够快不够狠）加大 P，或降速
舵机打满了还出弯不是 P 的事了，是速度超过过弯极限降速，或上差速
慢摆 直道大幅度、慢悠悠左右晃D 太小，超调收不住加 D
高频抖 / 筛糠 车身细碎快速哆嗦D 太大，放大了误差噪声减 D
反应迟钝 打角慢半拍、弯里LazyD 太大（过阻尼）或 P 小减 D 优先，再考虑加 P
直道很稳，一进弯就完蛋P 不够 + 速度太快加 P；P 加不动就降速
直道弯道都稳，就是慢参数还有余量提速，按第 6 节流程
记忆口诀：画龙退 P · 外冲加 P · 慢摆加 D · 筛糠减 D。
方向不确定时：P 管"打得够不够狠"，D 管"收得住收不住"。

3. 标准调参流程（十步法）

前提：DATA 页能正常显示 Err / IS / GY；电机基础 PWM 先调到低速档（1200 左右）。
  1. 推车验证：进 IMAGE 页，电机不转，用手推车沿赛道走，看屏幕上的红色中线跟不跟得住、舵机会不会随偏移打角。跟不住就是巡线/补线的问题，先修代码再调参。
  2. 低速发车：PWM=1200，P 用当前值，D 先给 P 的一半左右（比如 P=1.9 → D=1.0）。
  3. 观察直道：画龙 → 退 P；不画龙 → 进入下一步。
  4. 找 P 的画龙临界：每次 +0.1 加 P，直到直道开始出现轻微摆动，然后退回 20~30%。这就是当前速度的最佳 P。
  5. 调 D：D 从小往上加（步长 0.2），直到慢摆消失、又还没出现高频抖。取两者中间。
  6. 跑弯道：外冲 → 加 P（回到步骤 4 重新确认临界）；打满舵还出弯 → 降速。
  7. 提速一档：PWM +200~300。
  8. 重复 3~6。提速后 P 先保持不动试跑，画龙再退，外冲再加。
  9. 环岛专项：跑通后按第 7 节调 ISP/ISD。
  10. 记录：每一档速度的最终参数写进第 5 节的表里。比赛前按赛道直弯比例微调。

4. 调参铁律

① 一次只改一个参数。同时改 P 和 D，出了问题你永远不知道是谁的锅。
② 改之前记下原值。改崩了能一键回滚。
③ 每趟跑完写记录。不记录 = 白调，两周后你什么都不记得。
④ 低速调好再提速。低速都画龙的车上高速只有上天。
⑤ 现象决定方向，不靠猜。对着第 2 节的表查，表上没有的现象记下来问。
⑥ 每次改完跑同一条赛道同一段。场地变量都不控制，参数结论全是噪声。
⑦ 电池满电调出的参数，亏电时未必成立。比赛前在亏电状态复验一遍。

6. 提速专项：速度和 P/D 的关系

核心认知：车速本身会放大 P 的作用。物理上打同样的角，车速翻倍，横移速度也翻倍， 所以提速后 P 的第一反应是"收着点"，不是"跟上加"。
  • 响应速度 ωn 随 v 涨：ωn = v·√(gkP/L) —— 速度越快，同样的 P 响应越激进
  • ωn 有天花板（摄像头延迟 + 舵机延迟 ≈ 150ms → ωn ≤ 4 rad/s 左右），撞顶 = 画龙
  • D/P 比值随速度收窄：低速 1.5 左右 → 中速 1.0 → 高速 0.6 甚至更低
  • 降 P 会导致弯道外冲怎么办？—— 这才是差速 Kdiff 登场的时机：用差速补弯道，而不是无脑加 P

7. 环岛专项（ISP / ISD）

  1. 先把 ISP、ISD 设成和主 P、D 一模一样，跑通环岛再说。
  2. 入环瞬间猛甩一下 → 补线让误差瞬间阶跃，D 项踢腿 → 降 ISD。
  3. 环里画龙 → 降 ISP。环里压环岛边线 → 加 ISP。
  4. 环岛车速比直道低，模型上能撑更大的增益，所以 ISP/ISD 最终往往比主参数大 1.5~2 倍，从 1.5 倍起步往上试。
  5. 出环相关的是状态机的事（Yaw 差 335°），参数调不好出环去查 Island.c，别死调参。

8. 差速专项（Kdiff）

  • 公式：diff = Kdiff × (舵机输出 − 625)，左轮 = base − diff，右轮 = base + diff
  • 起点：模型算出 ≈2.8，从 2.5~3.0 开始
  • 弯里推头 → 加 Kdiff；直道开始晃 → 减 Kdiff（直道舵机偏移≈0，天然影响小）
  • 给 diff 加上限 ±400，防止急弯内轮被减成反转
  • 差速是弯道补强，直道稳不稳还是看 P/D，别指望差速救直道

9. 数学模型速查

自行车模型：δ 前轮角，L 轴距，v 车速
转弯半径 R = L / tan(δ) —— 过弯需要的打角只看弯的几何，与速度无关
闭环：ë = -(gv²k/L)(Pe + D·ė) —— 物理增益自带 v² 因子
ωn = v·√(gkP/L) —— P 决定修正快慢
ζ = D·√(gk)/(2√(PL)) —— D 决定阻尼（震荡倾向）
目标：ζ ≈ 0.7~0.9（轻微超调），ωn ≤ 0.65/τ（延迟限制）
D/P = 2ζ/ωn —— 比值随速度收窄，不是常数
  • 理论 Kdiff = base × d × k / (2L)，代入本车 ≈ 2.8
  • 模型给方向和量级，最终值以赛道实验为准
  • 模型里的 D 是"每秒"量纲，菜单里的 D 是"每帧"量纲，别直接搬数字

10. 新手常犯的错

  1. 同时调俩参数 → 测不出因果，铁律①
  2. 一画龙就猛加 D → 多数时候是 P 太大，退 P 才是首选
  3. 低速参数直接上高速 → 每档速度都要重走流程
  4. 在亏电电池上调参 → 电压掉，PWM-速度对应关系全变，白调
  5. 车抖先怪参数 → 先确认机械：舵机连杆虚位、轮子旷量、摄像头松动，机械问题参数救不了
  6. 只看车跑不跑，不看 DATA 页数字 → Err 收敛形态比肉眼更早告诉你问题
  7. 调好了不记录 → 下次掉电丢参数，原地去世

11. 黑话词典

词意思
画龙直道上左右周期性摆头，P 过大/带宽超限的典型震荡
推头 / 转向不足弯里车往弯外滑，转不过来
外冲弯道离心力+打角不足，车冲出弯道外侧
超调修到中线刹不住，冲过头的部分
阻尼 ζ"刹车力度"。<0.7 震荡，0.7~0.9 最佳，>1 迟钝
ωn（固有频率）"修正速度"。越大修得越快，受延迟限制有上限
饱和舵机/电机打到头了，输出加不上去
阶跃误差瞬间跳一截（比如环岛补线瞬间）
开环/闭环现在电机给 PWM 是开环（不管轮子实际转多快）；上编码器测速闭环后差速才精确
